# El software, por dentro

Segunda propuesta de portafolio. Mockup navegable y material de diseño para implementar después en Next.js. No contiene un proyecto Next.js ni una configuración de Railway.

## Abrir y revisar

Abrir `index.html` directamente en un navegador, o servir esta carpeta:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Visitar http://127.0.0.1:4173. No requiere instalación ni servicios externos.

## Interacciones disponibles

Las pestañas cambian el diagrama y su explicación. Funcionan con clic, flechas izquierda/derecha y Home/End. «Dentro del proyecto» expande las decisiones técnicas. Los enlaces de navegación llevan a secciones reales. Contacto es una sección pendiente de personalizar, no un formulario funcional.

## Alcance de esta entrega

El diseño se basa en el perfil proporcionado y en documentación/código de AC Maintainer. No se inventaron clientes, métricas, testimonios, disponibilidad laboral ni un enlace de certificación. La insignia tipográfica PCA es una composición propia, no un sello oficial de Google.

El nombre público, correo, GitHub, LinkedIn, verificación de la credencial y URL pública de demo siguen pendientes. La implementación final y el despliegue se realizarán desde el nuevo proyecto del usuario.
