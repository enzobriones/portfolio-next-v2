El servidor como punto de encuentro

Next.js consulta Fastify desde el servidor. El navegador recibe la interfaz y no necesita conocer la dirección privada de la API.

Sesiones fuera del JavaScript del navegador

La sesión utiliza una cookie HttpOnly. Los formularios se procesan con Server Actions y la API valida los datos con Zod.

Un dominio que conserva sus relaciones

Clientes, direcciones y equipos se persisten en PostgreSQL mediante Drizzle. El registro de un equipo requiere una dirección del cliente y un modelo de equipo.
